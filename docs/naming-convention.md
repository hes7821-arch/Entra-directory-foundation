# Naming Conventions & Identity Standards

## Group Naming Standard
All Security Groups in Microsoft Entra ID follow a standardized prefix structure:

* **Prefix Format:** `Sec-Dept-[DepartmentName]` or `Sec-Role-[RoleName]`
* **Case Sensitivity:** Title Case (`Sec-`)
* **Examples:**
  * `Sec-Dept-Executive`
  * `Sec-Dept-Finance`
  * `Sec-Dept-IT`
  * `Sec-Dept-Sales`
  * `Sec-Dept-HR`
  * `Sec-Dept-Contractors`

## User Principal Name (UPN) Standard
* **Format:** `firstname.lastname@hes7821gmail1515.onmicrosoft.com`
* **Rules:** All lowercase, separated by a dot, matching primary identity credentials.
